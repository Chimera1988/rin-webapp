# Неактивные исторические профили

Эти файлы сохранены только для анализа предыдущих версий. Исполняемый контур общения их не загружает.

Единственный серверный источник канонических правил модели: `public/data/rin_prompt_profile.json`.
Пользовательские изменения имени, описания, знаний и инициатив хранятся отдельно в `rin-profile-v1` и передаются серверу явно.
