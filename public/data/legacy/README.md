# Неактивные исторические профили

Эти файлы сохранены только для анализа предыдущих версий. Исполняемый контур общения их не загружает.

Канонический prompt-профиль хранится в `public/data/rin_prompt_profile.json`, но загружается только серверным модулем `lib/server/canonical-profile.js`. Браузер не передаёт канон и не может заменить `prompt_profile` или базовые серверные правила через тело `/api/chat`.

Пользовательские изменения имени, описания, знаний и дополнительных инструкций хранятся отдельно в `rin-profile-v1` и передаются серверу как ограниченные overrides.
